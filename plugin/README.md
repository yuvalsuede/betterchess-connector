# BetterChess plugin

One install, two things:

- **The engine** — the hosted BetterChess connector (`https://mcp.betterchess.co`). Sign in
  with a BetterChess account on first use; nothing runs on your machine.
- **The live coach skill** — how Claude coaches a chess.com game against a bot in the
  Claude browser: it arms the in-page rig once, the page draws the best move, the line,
  the threat and the losing captures on every move, and Claude explains the plan in the chat.

Free accounts get a daily analysis allowance. Pro ($5.99/mo) removes the cap and unlocks
`chess_review`. https://betterchess.co/subscribe

**Fair play:** bot games and finished games only. Engine help in a game against a person
gets accounts banned; the skill checks the page and refuses.
